# Soluciones Layer 2

Ethereum is powerful but has limited capacity. To help scale the network, Layer 2 (L2) solutions process transactions off-chain, reducing congestion and gas costs on Mainnet.

---

## 🧭 What is Layer 2?

Layer 2 refers to blockchain protocols built on top of Ethereum Mainnet (Layer 1) that inherit its security while offering better performance.

-⚡️ Faster and cheaper transactions  
- 🔐 Security rooted in Ethereum  
- 🌍 Supports growing dApp ecosystems  

---

## 🧩 Why do we need L2?

Ethereum can only handle ~15 transactions per second on Mainnet. Layer 2 helps:

- Scale transaction throughput  
- Lower gas fees  
- Support mass adoption  
- Enable real-time apps (games, social, payments)

---

## 🛠️ Types of Layer 2s

| Type             | Description                                            |
|------------------|--------------------------------------------------------|
| **Rollups**       | Bundle transactions off-chain and submit proofs to L1 |
| **Optimistic**    | Assume transactions are valid unless challenged       |
| **ZK-Rollups**    | Use zero-knowledge proofs to verify batches instantly |

---

## 🔝 Examples of Layer 2 Networks

| Name       | Type           | Notes                                               |
|------------|----------------|-----------------------------------------------------|
| **Arbitrum** | Optimistic     | Most popular L2 by total value locked               |
| **Optimism** | Optimistic     | Backed by Ethereum Foundation and major protocols  |
| **zkSync**   | ZK-Rollup      | Fast finality and low cost                          |
| **Base**     | Optimistic     | Built by Coinbase                                  |
| **Linea**    | ZK-Rollup      | Focus on EVM equivalence (by ConsenSys)            |
| **StarkNet** | ZK-Rollup      | Uses STARK proofs for high scalability              |

> 💡 Most L2s work seamlessly with MetaMask and popular dApps.

---

## 🔧 Using Layer 2s

To use a Layer 2 network:

1. Add the network to your wallet (e.g. via [Chainlist](https://chainlist.org))
2. Bridge ETH from Mainnet to the L2
3. Use dApps just like on Mainnet — with faster and cheaper transactions

Official L2 bridges:
- [Arbitrum Bridge](https://bridge.arbitrum.io)
- [Optimism Gateway](https://gateway.optimism.io)
- [zkSync Portal](https://portal.zksync.io)

In addition to official bridges, many reputable third-party bridges exist that offer support for multiple networks and additional features (like faster bridging or token swaps). However, these may charge additional fees and should be used with caution.

> ⚠️ Always verify bridge URLs from official or trusted sources. Avoid using unknown links to prevent scams.
