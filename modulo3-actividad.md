# 🕹️ Activity – SpeedRunEthereum Challenges

Welcome to your final activity for Module 3! This is your chance to apply everything you've learned about Solidity and smart contract development in a series of guided challenges.

You’ll complete a set of progressively harder levels designed to build practical skills, based on real-world Ethereum use cases.

---
## 🎯 Activity Objective

To demonstrate your understanding of smart contract development in Solidity by solving practical challenges from the [SpeedRunEthereum](https://speedrunethereum.com/) platform. You’ll write, test, and deploy contracts that simulate real-world tasks — from basic storage to NFT minting.

You will:
- Solve core Solidity challenges (levels 0 to 3)
- Work inside the Remix IDE or locally
- Submit your code and documentation in a public GitHub repository

By the end of this activity, you should feel confident building and deploying basic smart contracts in a real-world environment.
