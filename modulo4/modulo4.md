# Módulo 4: Desarrollo de Aplicaciones Web3

Este módulo representa el cierre del programa de onboarding y tiene como objetivo aplicar todos los conocimientos previos para construir una dApp funcional e integrada, usando herramientas reales del ecosistema Ethereum. Será el primer ejercicio completo en el que conectarás un contrato inteligente con una interfaz web, simulando un caso práctico como los que se presentan en proyectos reales de Ethereum Costa Rica.

---

## 🎯 Objetivos de aprendizaje

Al finalizar este módulo, serás capaz de:

- Comprender la arquitectura y componentes de una aplicación descentralizada (dApp).
- Integrar un contrato inteligente a un frontend React utilizando Ethers.js.
- Establecer conexiones seguras con MetaMask y leer/escribir datos en la blockchain.
- Desplegar contratos inteligentes en una testnet usando Hardhat.
- Documentar, versionar y presentar tu proyecto en GitHub de forma profesional.

---

## 📂 Estructura del módulo

Este módulo está dividido en seis secciones:

1. **[4.1 Introducción a las dApps](modulo4-1.md)**  
   Qué es una dApp, arquitectura, flujos y ejemplos.

2. **[4.2 Frontend Setup con React + Vite](modulo4-2.md)**  
   Creación del entorno de desarrollo para la interfaz Web3.

3. **[4.3 Conexión de Wallet (MetaMask)](modulo4-3.md)**  
   Lectura de cuenta activa, red y balance mediante Ethers.js.

4. **[4.4 Integración de Contrato Inteligente](modulo4-4.md)**  
   Llamadas `read` y `write` al contrato desde la interfaz.

5. **[4.5 Actividad Final: dApp Guiada](modulo4-actividad.md)**  
   Construcción de una aplicación completa paso a paso.

6. **[4.6 Qué Sigue (What's Next)](modulo4-cierre.md)**  
   Opciones para continuar explorando y construyendo en Web3.
