# 🧪 Módulo 4 - Actividad Final

### 🛠️ Construcción de una dApp de Mercado de Predicciones

Esta es la actividad final del Módulo 4 — un proyecto práctico y guiado en el que construirás una aplicación descentralizada real: una **dApp de Mercado de Predicciones** utilizando contratos inteligentes y un frontend basado en React.

No comenzarás desde cero. Seguirás un proyecto completo de código abierto, desarrollado con herramientas Web3 modernas, acompañado de un tutorial en video paso a paso.

---

### 🎯 Objetivo de la Actividad

Al finalizar esta actividad, habrás logrado:

* Interactuar con contratos inteligentes desde el frontend usando Thirdweb SDK
* Utilizar una interfaz para crear y resolver mercados de predicción
* Integrar conexiones con wallets Web3
* Administrar la lógica y estado de una dApp con React

---

## 📼 Proyecto: Simple Prediction Market

Seguí este tutorial en YouTube, que te guía paso a paso por todo el proceso:

▶️ **Video tutorial**: [Simple Prediction Market dApp](https://www.youtube.com/watch?v=BHLIJnS5Ikw&list=PLhkjr9MPgk0yFZ1noxemtaB_hsVs5JmQR)

📦 **Código fuente**: [Repositorio en GitHub](https://github.com/thirdweb-example/simple-prediction-market-youtube)

Vas a trabajar directamente con los archivos y estructura de este repositorio. Podés hacer un fork o clonarlo, y seguir las instrucciones del video.

---

## 🧰 Requisitos Previos

Antes de comenzar, asegurate de tener:

- MetaMask instalado 
- Node.js y npm configurados en tu equipo
- Editor de código 
- Consola o terminal funcional

## ✅ Entregable Final

Una vez completado el proyecto, debés subirlo a tu repositorio personal de GitHub utilizado para este programa de onboarding. Dentro del repositorio, creá una carpeta específica:

```
/modulo4/actividad-final/
```

El entregable debe incluir:

- El código completo del proyecto funcionando
- Un archivo `README.md` personalizado con:
  - Resumen de lo que hace tu aplicación
  - Instrucciones para instalar y correr el proyecto
  - Un breve párrafo sobre lo que aprendiste o se te dificultó

📤 Compartí el enlace a tu repositorio con el equipo de Ethereum Costa Rica para revisión.

> 🔐 Recordá mantener el repositorio público o permitir acceso a quienes deben evaluar tu entrega.

---

Con esta actividad completás el ciclo completo de desarrollo de una dApp: desde los conceptos básicos hasta la construcción e implementación de una aplicación funcional.
