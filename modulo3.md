# Módulo 3: Programando en Solidity

Este módulo está diseñado para brindarte una base sólida en Solidity, el lenguaje más utilizado para escribir contratos inteligentes en Ethereum. Ya sea que tengas experiencia en programación o estés comenzando en el mundo de Web3, este módulo te retará y te preparará para construir aplicaciones significativas utilizando las herramientas y patrones fundamentales del ecosistema Ethereum.

---

## 🎯 Objetivos de aprendizaje

Al finalizar este módulo, serás capaz de:

- Comprender la estructura y el ciclo de vida de un contrato inteligente en Solidity.
- Utilizar las características principales del lenguaje: variables, funciones, modificadores, visibilidad y estructuras de control.
- Aplicar buenas prácticas de desarrollo y optimización de gas.
- Integrar librerías externas como OpenZeppelin para mayor seguridad y reutilización de código.
- Compilar, probar y desplegar contratos usando herramientas como Remix y Hardhat.
- Completar desafíos prácticos que consoliden tus habilidades como desarrollador Web3.

---

## 🧱 Estructura del Módulo

Este módulo está dividido en seis secciones:

1. **[3.1 Fundamentos de Solidity](modulo3-1.md)**  
   Historia, comparación de lenguajes, sintaxis básica y primer contrato.

2. **[3.2 Estructura y Anatomía de un Contrato](modulo3-2.md)**  
   Layout del archivo, variables de estado, constructor, eventos y errores.

3. **[3.3 Tipos, Funciones y Control de Flujo](modulo3-3.md)**  
   Tipos de datos, visibilidad, `memory` vs `storage`, condicionales, loops y modificadores.

4. **[3.4 Librerías, Compilación y Buenas Prácticas](modulo3-4.md)**  
   Uso de OpenZeppelin, compilación (`solc`), ABI, metadata y optimización de gas.

5. **[3.5 Actividad – SpeedRunEthereum](modulo3-actividad.md)**  
   Retos prácticos con contratos reales del ecosistema.

6. **[Cheatsheet y Recursos de Referencia](modulo3-cheatsheet.md)**  
   Acceso rápido a sintaxis, comandos clave y documentación oficial.

## 📂 Entregables

Durante las primeras secciones (3.1 a 3.4), se espera que realices pequeñas pruebas en Remix o localmente. Podés guardar tu código en tu repositorio personal de GitHub como referencia.

La principal actividad evaluada será:

- La resolución completa de los retos de **SpeedRunEthereum** (challenges 0 a 3).
- Subida del código fuente y README por cada reto en GitHub.
- Capturas o registros de pruebas realizadas.
