# Módulo 3: Programando en Solidity

Este módulo está diseñado para brindarte una base sólida en Solidity, el lenguaje más utilizado para desarrollar contratos inteligentes en Ethereum. Tanto si tenés experiencia en programación como si estás dando tus primeros pasos en Web3, este módulo te retará y te preparará para construir aplicaciones significativas utilizando herramientas, patrones y estándares del ecosistema Ethereum.

---

## 🎯 Objetivos de aprendizaje

Al finalizar este módulo, serás capaz de:

- Comprender la estructura y el ciclo de vida de un contrato inteligente en Solidity.
- Utilizar las características principales del lenguaje: variables, funciones, modificadores, visibilidad y estructuras de control.
- Aplicar buenas prácticas de desarrollo, seguridad y optimización de gas.
- Integrar librerías externas como OpenZeppelin para mayor seguridad y reutilización de código.
- Compilar, probar y desplegar contratos utilizando herramientas como Remix y Hardhat.
- Completar desafíos prácticos que consoliden tus habilidades como desarrollador Web3.

---

## 🧱 Estructura del módulo

Este módulo está dividido en seis secciones:

1. **[3.1 Fundamentos de Solidity](modulo3-1.md)**  
   Historia, propósito, sintaxis básica y primer contrato.

2. **[3.2 Anatomía de un Contrato](modulo3-2.md)**  
   Layout del archivo, variables de estado, constructor, funciones, eventos y errores.

3. **[3.3 Tipos, Funciones y Control de Flujo](modulo3-3.md)**  
   Tipos de datos, visibilidad, `memory` vs `storage`, estructuras condicionales y bucles.

4. **[3.4 Librerías, Compilación y Buenas Prácticas](modulo3-4.md)**  
   Uso de OpenZeppelin, compilación (`solc`, ABI), pruebas básicas y consideraciones de seguridad.

5. **[3.5 Actividad – SpeedRunEthereum](modulo3-actividad.md)**  
   Retos prácticos utilizando herramientas y contratos reales del ecosistema.

6. **[Cheatsheet y Recursos de Referencia](modulo3-cheatsheet.md)**  
   Acceso rápido a sintaxis, comandos clave y enlaces útiles a documentación oficial.

---

## 📂 Entregables

Durante las secciones 3.1 a 3.4, deberás realizar ejercicios prácticos en Remix o localmente. Estos no requieren entrega formal, pero te recomendamos subir tu progreso a un repositorio personal de GitHub.

La actividad evaluada principal del módulo será:

- La resolución completa de los retos 0 a 3 de **SpeedRunEthereum**.
- Subida del código fuente y archivos README para cada reto en tu repositorio personal.
- Capturas o registros de pruebas realizadas.
